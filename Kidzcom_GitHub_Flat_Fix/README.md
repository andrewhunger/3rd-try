# Kidz.com website - Photo-Led Neutral

This version is deliberately built without folders. Every website file sits at the top level of the GitHub repository, matching the way Andrew's browser uploads files.

## Uploading this version

1. Extract the ZIP on your computer.
2. Open the extracted folder.
3. Select every file inside it.
4. In the existing GitHub repository, choose **Add file > Upload files**.
5. Drop the selected files onto GitHub and commit them.

Files with matching names will replace the current versions. GitHub keeps the previous commit, so the earlier theme remains recoverable.

## Main files

- `index.html` - homepage
- `programmes.html` - before- and after-school care
- `holidays.html` - holiday programme
- `parent-info.html` - parent information and enrolment
- `oscar-subsidy.html` - current subsidy guide, income thresholds and application steps
- `about.html` - approach and staff profiles
- `blog.html` - termly blog index
- `july-holidays.html` - sample blog post
- `styles.css` - colours, layout and responsive design
- `staff.js` - the single editable list of staff names, roles, profiles, alter egos and image filenames
- `site.js` - mobile menu, staff-card creation and staff-photo flipping
- `kidz-logo.png` - the existing Kidz.com logo
- `photo-creative.svg`, `photo-active.svg`, `photo-together.svg` - neutral placeholders for approved homepage photographs

## Future edits

Each file can be edited separately in GitHub. Wording changes normally affect one `.html` file. Colour or layout changes normally affect `styles.css`. Staff changes happen in `staff.js`. Mobile-menu or photo-flip changes affect `site.js`. Check the figures in `oscar-subsidy.html` after Work and Income updates its rates each April.

The preview still uses placeholder staff and activity images. Work through `CONTENT_CHECKLIST.md` before public launch.
